作品規格書（本頁實作對應）

目標使用者第一次整合感測器、顯示器與輸出模組的 ESP32 初學者。
核心問題接線時容易忘記 GPIO 已被占用，或誤把僅輸入腳拿來控制輸出。
互動功能勾選模組、調整腳位、衝突檢查、圖像化佔用、瀏覽器儲存與 JSON 匯出。
查看完整規格與 AI 協作紀錄

發想：我想做一個不是只有展示資訊、而是真的能在做 ESP32 小專題前使用的網頁工具。因此把「模組選擇、腳位規劃與基本錯誤預防」整合在同一個畫面。

  1. 使用者可選擇 BME280、OLED、旋鈕、按鈕、伺服馬達、NeoPixel 與馬達驅動器。
  2. 系統依模組預設接線建立表格；I2C 裝置可共用 SDA/SCL，其他重複輸出／輸入會標示衝突。
  3. 將 ESP32 常見的 GPIO 34、35、36、39 標為僅輸入；若配置為輸出功能會扣分並提醒。
  4. 使用者可以儲存目前方案在瀏覽器，或匯出 JSON 作為下一步接線／寫程式的參考。

技術限制：本作品是單一 index.html，所有 CSS 與 JavaScript 皆內嵌；不需伺服器或外部套件，可直接部署至 GitHub Pages。它提供規劃建議，實際接線前仍須依模組資料表確認電壓、啟動腳與電流需求。
